# پروژه‌های درس یادگیری عمیق

این مخزن شامل پنج تمرین عملی درس **یادگیری عمیق** است. پروژه‌ها با Python و در محیط Google Colab پیاده‌سازی شده‌اند و موضوعاتی مانند رگرسیون، انتقال یادگیری، شبکه‌های مولد و تشخیص اشیا را پوشش می‌دهند.

## تمرین ۱: پیش‌بینی قیمت مسکن

در این تمرین یک مدل رگرسیون خطی به روش پرسپترون و گرادیان‌کاهشی، بدون استفاده از مدل رگرسیون آماده، روی دیتاست Boston Housing پیاده‌سازی شده است.

### مراحل

- دریافت دیتاست از OpenML
- تحلیل همبستگی ویژگی‌ها
- انتخاب ویژگی‌های `RM` و `LSTAT`
- تقسیم داده به train و test
- استانداردسازی ویژگی‌ها و متغیر هدف
- پیاده‌سازی Gradient Descent از ابتدا
- ارزیابی با MSE، RMSE، MAE و R²
- رسم نمودار Loss و صفحه رگرسیون سه‌بعدی

### نتایج

| معیار | مقدار |
|---|---:|
| MSE | 31.243 |
| RMSE | 5.590 |
| MAE | 3.899 |
| R² | 0.574 |

فایل اصلی:


## تمرین ۲: طبقه‌بندی ۱۷ گونه گل

در این تمرین تصاویر دیتاست Oxford 17 Flowers با استفاده از انتقال یادگیری و EfficientNetB0 طبقه‌بندی شده‌اند.

### مراحل

- آماده‌سازی ۱۷ کلاس گل
- تقسیم داده به train، validation و test

- آموزش اولیه سر طبقه‌بندی
- Fine-tuning لایه‌های انتهایی
- استفاده از ModelCheckpoint و EarlyStopping
- محاسبه Precision، Recall و F1-score
- رسم Confusion Matrix
- پیش‌بینی تصاویر داخل و خارج دیتاست

## تمرین ۵: تشخیص وسایل نقلیه با YOLOv5

### کلاس‌ها

```text

Bicycle
Bus
Truck
Motorcycle
```

### مراحل

- دریافت و استخراج تصاویر وسایل نقلیه
- یکسان‌سازی فرمت تصاویر
- تولید pseudo-label اولیه با YOLOv5s
- آماده‌سازی قالب استاندارد YOLO
- تقسیم داده به train، validation و test
- آموزش YOLOv5s، YOLOv5m و YOLOv5l
- مقایسه Precision، Recall، mAP و سرعت
- انتخاب مدل برتر
- رسم نمودارها و تصاویر پیش‌بینی
- تولید گزارش نهایی
